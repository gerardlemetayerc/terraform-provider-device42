# device42_ip (Resource)


## Exemple 

```hcl
data "device42_subnet" "subnet" {
  name = "Infra"
}

resource "device42_device" "host" {
  name               = var.name
  archive_on_destroy = "true"
  service_level      = var.servicelevel
}

resource "device42_ip" "ip" {
  subnet_id    = data.device42_subnet.subnet.subnet_id
  suggest_ip   = true
  available    = "no"
  vrf_group_id = data.device42_subnet.subnet.vrf_group_id
  device_id    = tonumber(device42_device.host.id)
}

resource "device42_ip" "ip2" {
  subnet_id = data.device42_subnet.subnet.subnet_id
  ip        = "192.168.1.100"
  available = "no"
}
```

## Schema

### Optional

- `ip` (String) Network of the subnet. Required for creation, cannot be modified after subnet creation.
- `subnet_id` (Int) Subnet ID.
- `available` (String) Whether the IP is available or not. Typically "yes" or "no".
- `vrf_group_id` (Int) Subnet VRF Group ID.
- `device_id` (Int) ID of the device to attach to the network.
- `suggest_ip` (Bool) A boolean indicating if the Device42 IP suggestion functionality should be used to retrieve an available IP. If true and ip is not specified, the provider will automatically fetch a suggested IP.
- `tags` (String) Comma-separated list of tags to set on the IP address. Requires the API to be queried with `include_cols=tags` to be read back.

~> **Note:** the Device42 IP API only **appends** tags to an IP; setting `tags` never removes existing ones. Any tags already present on the IP are kept, so this option is best used to add/adjust tags when you can tolerate the existing set being preserved. Removing a tag requires clearing it through the Device42 API directly.

### Read-Only

- `id` (String) The ID of this resource.


## Import

IP addresses can be imported using the Device42 IP id, e.g.

```bash
$ terraform import device42_ip.myIp <ip_id>
```
